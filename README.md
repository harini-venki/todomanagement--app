# Todo Management Application

A responsive Todo Management Application built using HTML, CSS, and JavaScript with the DummyJSON Todos API.

## Features

- View todo tasks
- Add new tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Save tasks in browser localStorage
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML
- CSS
- JavaScript
- DummyJSON Todos API
- Browser localStorage

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Use the application to add, edit, complete, and delete tasks.
